# Durable Memory

Store only information useful across future sessions. Prefer short, dated entries. Separate confirmed facts from tentative patterns.

## Memory rules

- Add dates to new entries.
- Mark uncertain observations as `Tentative` until repeated or confirmed.
- Correct outdated information instead of allowing contradictions to accumulate.
- Do not store secrets or sensitive identifiers.
- Do not store raw transcripts, full calendar dumps, or other people's private details.
